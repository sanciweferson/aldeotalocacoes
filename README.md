# Aldeota Locações — Landing Page

Primeira versão do site institucional da Aldeota Locações.

## Stack

- Next.js 16
- TypeScript
- Tailwind CSS 4
- Lucide React
- SVGs criados no próprio código (sem depender de fotos)
- Tema claro/escuro com preferência salva em `localStorage`
- SEO local básico + JSON-LD de negócio local
- Sem banco de dados

## Rodar no WSL

```bash
npm install
npm run dev
```

Depois abra: http://localhost:3000

## Antes de publicar para o cliente

1. Confirmar catálogo real de equipamentos.
2. Confirmar telefone e endereço.
3. Confirmar textos sobre entrega, retirada e condições de locação.
4. Confirmar avaliação e quantidade de avaliações do Google.
5. Quando houver domínio, adicionar a URL real ao metadata/canonical e ao sitemap.

## Observação

Esta versão usa textos iniciais para prototipagem. O visual e a estrutura estão prontos para refinamento com informações oficiais da empresa.
